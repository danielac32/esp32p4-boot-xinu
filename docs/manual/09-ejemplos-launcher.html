1. Lo que existe hoy

1.1 Ubicaciones

LugarContenido

/apps/ (microSD, en la placa)Apps instaladas. Cada una en /apps/<nombre>/ con app.elf, icon.jpg, app.txt. El launcher vive en /apps/launcher/app.elf (se excluye del listado).

1.2 Formato de instalación: /apps/<dir>/

/apps/miapp/app.elf    → binario ET_REL RV32 (ld -r)
/apps/miapp/icon.jpg   → ícono alusivo (≈96×96), mostrado por LVGL (S: + SJPG)
/apps/miapp/app.txt    → metadatos para el launcher

app.txt (clave=valor):

name=Mi App
exec=/apps/miapp/app.elf
icon=S:/apps/miapp/icon.jpg
color=0x6688AA

Si falta name usa el nombre del directorio; si falta exec asume /apps/<dir>/app.elf. El exec es la identidad ante appmgr (reutiliza slot por path), así que la app debe registrarse con la misma ruta que pone aquí.

2. Cómo funciona el mecanismo (profundidad)

2.1 appmgr — el registro cooperativo

Tabla fija table[APPMGR_MAX] (8) en el kernel, exportada. Sin MMU, kernel y apps comparten memoria → basta con llamadas exportadas. Estados: APP_FREE, APP_RUNNING (al frente, pinta/atiende gestos), APP_BACKGROUND (oculta UI, puede seguir viva — p. ej. música), APP_CLOSING (cierre pedido, la app debe salir limpiamente).

FunciónComportamientoLlamador típico
appmgr_register(name,path,color,tid)Busca slot por path (find_path) y lo reutiliza, o toma uno FREE; copia nombre/path/color/tid, state=APP_RUNNING. Devuelve slot o SYSERR.La app, al arrancar
appmgr_unregister(slot)Marca APP_FREE, limpia.La app, al salir
appmgr_find_path/find_tidLocaliza slot.Launcher, app_runner
appmgr_get_state/set_stateLee/escribe estado.App (obedece), launcher
appmgr_request_close(slot)Pone APP_CLOSING (cooperativo).Launcher (botón X)
appmgr_take_foreground(slot)Pasa a fondo los APP_RUNNING y pone slot al frente.Launcher (retomar)
Cooperativo. El launcher no hace kill() directo: pide APP_CLOSING y la app limpia (LVGL, audio, hilos propios, appmgr_unregister) y hace exit(). Así se evitan fugas/corrupción de UI y audio.

2.2 El launcher: de tocar un ícono a ejecutar el ELF

  1. Descubrimiento: fl_opendir("/apps") + fl_readdir; ignora . y no directorios y el directorio launcher; para cada uno lee /apps/<dir>/app.txt (lee_archivo) y rellena app_info {name,exec,icon,color}.
  2. Home: grilla de íconos (lv_img con S:/SJPG) sobre controles de gestos (sin texto de nombre). Rendimiento: decode SJPG desde SD, secuencial → aparecen de a uno; solución recomendada: cache RGB565 en PSRAM o .bin pre-convertido.
  3. Lanzar/retomar: al tocar, busca appmgr_find_path(exec). Si ya hay instancia, take_foreground y muestra su UI. Si no, create(..., app_runner, APP_PRIO, "app", 1, exec) (pila RUN_STK, p. ej. 16 KB) y oculta el launcher (gestos_show(g,0)).
  4. app_runner(char *path): r = elf_run(path, 0, NULL); si falla, localiza slot por path y appmgr_unregister. Corre en su propia hebra; elf_run salta al app y al terminar (exit→kill) la hebra muere y el kernel libera la imagen ELF en PSRAM.
  5. Conmutador/fondo: swipe arriba → la app se pone APP_BACKGROUND y oculta UI. Swipe arriba en el launcher → tarjetas de activas (Retomar / X). X → request_close. Un vigía detecta cuando no hay APP_RUNNING y vuelve a mostrar el home.
static int app_runner(char *path) {
    int r = elf_run(path, 0, NULL);
    if (SYSERR == r) { int slot = appmgr_find_path(path); if (slot >= 0) appmgr_unregister(slot); }
    return 0;
}

3. Guía: crear una app nueva con pantalla (paso a paso)

Paso A — Diseña la app. Define: (1) nombre/ruta /apps/miapp/app.elf; (2) pantallas (P_HOME, P_DETALLE…); (3) los IDs de botones; (4) los datos que manejas (listas, buffers, conexión) y qué viene de servicios del kernel (wifinet, fl_*, mp3_*, appmgr).
Paso B — Crea la carpeta.
examples/p4-elfsdk/apps/miapp/
  miapp.c
  Makefile
(reusa ../lib/start.S y, si usas UI, ../lib/gestos.c ../lib/gestos.h)
Paso C — Define la estructura de estado (lo primero en el .c). Sin estáticas mutables: todo aquí. Incluye UI, appmgr, máquina de pantallas, punteros LVGL, buffers y la señal volatile accion si habrá callbacks que disparen trabajo.
#include <stdio.h>
#include <string.h>
#include <kernel.h>
#include <thread.h>
#include <timer.h>
#include <memory.h>
#include <appmgr.h>
#include "gestos.h"          /* trae lvgl/lvgl.h; o incluye <lvgl.h> si vas directo */

void exit(int codigo);

#define P_HOME    0
#define P_INFO    1
#define B_INFO    1
#define B_VOLVER  2
#define B_SALIR   9

struct miapp {
    gestos_t    *g;
    int          slot;
    int          pantalla;
    int          contador;
    char         texto[64];
    volatile int accion;      /* para callbacks (teclado/eventos) → bucle main */
};
Paso D — Funciones de pantalla (una por vista). Cada una limpia botones, pinta su contenido y fija m->pantalla.
static void ver_home(struct miapp *m) {
    gestos_botones_limpiar(m->g);
    gestos_pastilla(m->g, "Mi App");
    sprintf(m->texto, "Veces: %d", m->contador);
    gestos_nota(m->g, m->texto);
    gestos_boton(m->g, B_INFO,  "VER INFO", 40, 180, 240, 55, 0x2A6A9A);
    gestos_boton(m->g, B_SALIR, "SALIR",    40, 360, 240, 50, 0xB04040);
    m->pantalla = P_HOME;
}
static void ver_info(struct miapp *m) {
    gestos_botones_limpiar(m->g);
    gestos_pastilla(m->g, "Info");
    gestos_nota(m->g, "Pantalla de detalle");
    gestos_boton(m->g, B_VOLVER, "VOLVER", 40, 360, 240, 50, 0x666666);
    m->pantalla = P_INFO;
}
Paso E — Bucle principal, despacho de eventos y ciclo cooperativo.
static void bucle(struct miapp *m) {
    for (;;) {
        int st = appmgr_get_state(m->slot);
        if (st == APP_CLOSING) break;
        if (st == APP_BACKGROUND) { sleep(100); continue; }
        if (m->accion) { m->accion = 0; /* procesar trabajo pedido por callback */ }

        gev_t ev;
        if (!gestos_leer(m->g, &ev)) { sleep(50); continue; }

        if (ev.tipo == GE_ARRASTRE && ev.dir == GE_ARRIBA) {
            gestos_show(m->g, 0);
            appmgr_set_state(m->slot, APP_BACKGROUND);
            continue;
        }
        if (ev.tipo != GE_BOTON) continue;

        if (m->pantalla == P_HOME) {
            if (ev.id == B_INFO)  { m->contador++; ver_info(m); }
            if (ev.id == B_SALIR) break;
        } else if (m->pantalla == P_INFO) {
            if (ev.id == B_VOLVER) ver_home(m);
        }
    }
}

Nota: si tu app vuelve a frente tras fondo, detecta el cambio de estado a APP_RUNNING y haz gestos_show(m->g,1)/redibuja (patrón real de las apps).

Paso F — main: crear estado, UI, registrar, ejecutar, limpiar.
int main(int argc, char *argv[]) {
    (void)argc; (void)argv;
    struct miapp *m = psram_malloc(sizeof(*m));
    if (!m) exit(1);
    memset(m, 0, sizeof(*m));

    m->g = gestos_nueva_partes(GE_PASTILLA|GE_NOTA);
    if (!m->g) { psram_free(m); exit(1); }
    m->slot = appmgr_register("miapp", "/apps/miapp/app.elf", 0x6688AA, gettid());

    ver_home(m);
    bucle(m);

    gestos_cerrar(m->g);
    appmgr_unregister(m->slot);
    psram_free(m);
    exit(0);
}
Paso G — Makefile (patrón medido del SDK). Banderas obligatorias: -fno-pic -ffunction-sections -std=gnu11 -march=rv32imaf_zicsr_zifencei -mabi=ilp32f -mno-relax -msmall-data-limit=0 -Wall, includes del kernel/lvgl/fatfs/plataforma y ../lib, enlace con ld -r.
TOPDIR = ../../../..
CC = riscv32-unknown-elf-gcc
LD = riscv32-unknown-elf-ld
CFLAGS = -Os -fno-builtin -fno-pic -ffunction-sections -std=gnu11 \
  -march=rv32imaf_zicsr_zifencei -mabi=ilp32f -mno-relax -msmall-data-limit=0 -Wall \
  -I$(TOPDIR) -I$(TOPDIR)/include -I$(TOPDIR)/lvgl -I$(TOPDIR)/fatfs \
  -I$(TOPDIR)/system/platforms/esp32p4 -I../lib
APP  = miapp
OBJS = miapp.o ../lib/gestos.o ../lib/start.o
all: $(APP).elf
$(APP).elf: $(OBJS)
	$(LD) -r -o $@ $(OBJS)
%.o: %.c
	$(CC) $(CFLAGS) -c -o $@ $<
../lib/gestos.o: ../lib/gestos.c ../lib/gestos.h
	$(CC) $(CFLAGS) -c -o $@ $<
../lib/start.o: ../lib/start.S
	$(CC) $(CFLAGS) -c -o $@ $<
clean:
	rm -f miapp.o $(APP).elf
.PHONY: all clean

Paso I — Checklist antes de dar por buena la app.
  • Sin variables globales/estáticas mutables (todo en struct miapp en psram_malloc).
  • appmgr_register con la ruta exacta de exec; appmgr_unregister al salir.
  • Obedece APP_CLOSING; gestiona APP_BACKGROUND (gestos_show 0/1). Sin kill() propio forzado.
  • Callbacks LVGL: solo señalan (m->accion), nada de exit/lock/I/O pesado.
  • gestos_cerrar → appmgr_unregister → psram_free → exit(0) desde main.
  • Si usa FAT: respeta no-truncado al sobrescribir (fl_remove antes) y la concurrencia del bus compartido.
