Manual técnico — Xinu-P4.2 (ESP32-P4)

Documentación en profundidad del port bare-metal RISC-V: plataforma, kernel, build, dispositivos, red, shell, ELF/PSRAM, ejemplos y LVGL. Basada en el árbol /home/daniel/xinu-p4.2 (2026-11).

Cómo usar este manual. Es un conjunto de páginas enlazadas (dashboard). Cada sección cita rutas reales del código (system/, loader/, machine/, device/, compile/, examples/) y describe el comportamiento medido/implementado en este port. Complementa al tablero general docs/xinu-p4-dashboard.html.
Notas vigentes: DMA del LCD (AXI-DMA→SPI2) no estabilizado (queda PIO + fallback); ver docs/README. Íconos del launcher lentos por decode SJPG desde SD: solución recomendada, cache RGB565 en PSRAM o .bin pre-convertido. P4_TIMER_FREQ declarado 360 MHz vs ~320 MHz reales (delays/ticks ~9/8 largos). DEPFLAGS vacío: tras tocar headers/linker, make clean.
